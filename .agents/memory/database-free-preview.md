---
name: Database-free visual preview
description: User requirement for viewing the app's interface without a database connection.
---

The user wants to be able to visually inspect the app without connecting a database. A preview without a database must be clearly labeled and must not imply that authentication, financial actions, or stored data are available.

**Why:** The user explicitly asked to preview the project without connecting the database.

**How to apply:** Preserve the database-free visual preview path for UI work. Keep database-dependent actions disabled and do not fabricate balances, transactions, or account activity.
